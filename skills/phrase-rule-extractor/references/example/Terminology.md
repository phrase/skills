**Terminology.** These are deterministic terms to use or avoid, pulled out for import into the platform's Term Base — not Style Guide Rules.

| Source term (en-US) | Target term (de-DE) | Do not use | Note |
| --- | --- | --- | --- |
| Adidas | adidas | Adidas | The brand is written in lowercase. |
| boot | Fußballschuh | Stiefel, Boot | Do not put Schuh in avoid: it is part of the correct term Fußballschuh. boot -> Fußballschuh |
| boot pack | Schuhkollektion | Schuh-Pack, Boot-Pack | boot pack -> Schuhkollektion |
| cleat | Fußballschuh | Cleat | cleat -> Fußballschuh |
| colorway | Farbvariante | Colorway | colorway -> Farbvariante |
| pack | Kollektion | Pack | Pack -> Kollektion, also in compounds. |
| pitch | Rasen | Platz, Spielfeld | pitch -> Rasen |
| silhouette | Modellreihe | Silhouette | silhouette -> Modellreihe |
| team | Team | Mannschaft | The client writes Team, not Mannschaft. |
| World Cup | WM | Weltmeisterschaft | World Cup -> WM |
